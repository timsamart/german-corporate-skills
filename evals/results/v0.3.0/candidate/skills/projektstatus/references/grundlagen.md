# Grundlagen und Grenzen

Recherche: 5. Oktober 2026.

- [V-Modell XT Bund 2.4](https://ftp.tu-clausthal.de/pub/institute/informatik/v-modell-xt/Releases/2.4-Bund/Dokumentation/V-Modell-XT-Bund-Gesamt.pdf), 2024, C.1.8.3: Statusberichte verbinden Ergebnisse, Qualität, Risiken, Abweichungen und nächste Planung. Für zusammengefasste Berichte ist ein gemeinsamer Stichtag bedeutsam. Kontext: Entwicklungsprojekte des Bundes.
- [Scrum Guide 2020, deutsche Übersetzung](https://scrumguides.org/docs/scrumguide/v2020/2020-Scrum-Guide-German.pdf): Wo Scrum verwendet wird, hängt ein fertiges Inkrement von der vereinbarten Definition of Done ab. Eine Sprint Review untersucht Ergebnisse und Anpassung. Dies begründet keinen Scrum-Zwang für andere Projekte.

Ampelschwellen und Fortschrittsdefinitionen kommen aus dem Unternehmen. Eine Änderung der Planung kann sinnvoll sein; der Vergleich mit dem bisherigen genehmigten Stand bleibt sichtbar. Ein Bericht ersetzt weder fachliche Abnahme noch das Beheben einer Abweichung.
