# Eine Einweisungsfolie
**Synthetischer Transferfall. Alle Personen, Organisationen, Zahlen und Situationen sind erfunden.**

Zweck: Neue Mitarbeitende sollen im internen Buchungssystem einen Besprechungsraum buchen können. Im Anschluss erhalten sie dieselbe Folie im Teamchat.

Bisheriger Folientext:
Titel: „Prozedur zur Initiierung einer Raumreservierung“
1. Im Menü „Arbeitsplatz“ öffnen.
2. Unter „Raum“ einen freien Raum und das gewünschte Zeitfenster auswählen.
3. „Bestätigen“ anklicken.

„Arbeitsplatz“, „Raum“ und „Bestätigen“ sind die genauen sichtbaren Beschriftungen im System. Nach dem Klick auf „Bestätigen“ erscheint die Reservierung automatisch im persönlichen Kalender. Es gibt keine weitere Freigabe.
