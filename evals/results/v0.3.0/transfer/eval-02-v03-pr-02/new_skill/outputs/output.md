# Raum buchen

1. Öffne im Buchungssystem das Menü „Arbeitsplatz“.
2. Wähle unter „Raum“ einen freien Raum und das gewünschte Zeitfenster.
3. Klicke auf „Bestätigen“.

**Fertig:** Die Reservierung erscheint automatisch in deinem persönlichen Kalender. Eine weitere Freigabe ist nicht nötig.

**Einschätzung:** Inhaltlich fehlt für die dreiminütige Einweisung nach dieser Ergänzung nichts Wesentliches; geprüft wurde ausschließlich der Text dieser einen Folie.
